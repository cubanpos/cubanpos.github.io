Entrar para editar la web

Los cambios se guardan en GitHub y todos los visitantes los ven en unos minutos. Necesitas tu llave de acceso (token) de GitHub; se queda solo en este navegador.

Repositorio y rama
¿Cómo saco la llave de acceso?
  1. En GitHub, con la cuenta cubanpos, abre Configuración › Tokens de acceso.
  2. Nombre: Panel web. Vencimiento: el que prefieras (por ejemplo, un año).
  3. En Repository access elige Only select repositories y marca cubanpos.github.io.
  4. En Permissions › Contents elige Read and write.
  5. Pulsa Generate token, cópialo y pégalo arriba. GitHub no lo vuelve a mostrar.
